# 📚 Obsidian-Estudos

Meu vault único do Obsidian: estudos (concurso e programação), leituras, projetos e prompts para usar com o Claude.

## 🗂️ Estrutura

```
OBSIDIAN/
├── CLAUDE.md               ← guia do vault para o Claude
├── 00 Inbox/               ← notas novas e rascunhos
├── 01 Diário/              ← notas diárias (privado, fora do Git)
├── 02 Projetos/            ← uma pasta por projeto
├── 03 Estudos/
│   ├── Concurso/           ← Direito Constitucional, Português, editais, provas
│   ├── Programação/        ← Git, HTML, CSS, JS, Node, React, TS, Next, Python...
│   └── Livros técnicos/    ← fichamentos (Entendendo Algoritmos)
├── 04 Leitura/
│   ├── Anotações/          ← anotações de livros pessoais
│   └── Biblioteca/         ← PDFs e ebooks (fora do Git)
├── 05 Claude/
│   ├── Prompts/            ← prompts reutilizáveis
│   └── Contextos/          ← contextos pessoais (privado, fora do Git)
├── 90 Templates/           ← Diário, Projeto, Prompt, Nota de estudo
├── 98 Documentos/          ← documentos pessoais (privado, fora do Git)
└── 99 Anexos/              ← imagens e anexos
```

## 🤖 Usando com o Claude

Abra a pasta do vault no Claude Code. O `CLAUDE.md` explica a estrutura e as regras, e há comandos prontos:

- `/novo-projeto <nome> <descrição>`: cria o projeto em `02 Projetos/` a partir do template
- `/salvar-prompt <nome>`: salva um prompt reutilizável em `05 Claude/Prompts/`
- `/diario <texto>`: registra na nota diária de hoje (ou resume a semana)

## 🔒 Privacidade

Este repositório é público. `01 Diário/`, `05 Claude/Contextos/`, `98 Documentos/` e todos os PDF/epub/mobi estão no `.gitignore`.

## 🛠️ Plugins

Admonition, Iconize, Calendar, Code Emitter, List Callouts, Editing Toolbar, Style Settings, Awesome Reader, Obsidian Git, Highlightr e Excalidraw.
